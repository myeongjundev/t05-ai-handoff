# AI A → AI B 인계 문서

> 이 파일은 AI A의 계획 중단 직전에 실제 값으로 채운다. AI B에는 저장소와 이 파일만
> 제공하며, 첫 대화 전문은 제공하지 않는다.

## 1. 목표

`원본 ↔ 카드 비교 슬라이더`를 완성하고 `docs/EXPERIMENT_PLAN.md`의 검사 10개를 통과한다.

## 2. 현재 상태

- 시작 커밋: `미기입`
- 마지막 커밋: `미기입`
- 바뀐 파일: `미기입`
- 지금 화면에서 되는 것: `미기입`

## 3. 실행 명령

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

성공 기준: 테스트가 실패 없이 끝나고 터미널에 표시된 로컬 주소에서 앱이 열린다.

## 4. 통과한 검사

- 통과: `없음 — AI A 중단 시 번호로 갱신`
- 실패: `없음 — AI A 중단 시 번호와 증상으로 갱신`
- 미실행: `1~10`

## 5. 남은 문제

- `AI A 중단 시 재현 단계와 함께 작성`

## 6. 다음 행동

1. 이 문서만 보고 앱과 테스트를 실행한다.
2. 검사 번호 순으로 남은 구현을 끝낸다.
3. 관련 검사 뒤 전체 10개와 기존 테스트를 다시 실행한다.

## 7. 건드리면 안 되는 부분

- 검사 10개의 의미와 AI별 예산을 작업 중 바꾸지 않는다.
- 비교 UI 상태를 카드 저장 스키마나 공유 링크에 넣지 않는다.
- 기존 카드 렌더러 결과를 비교 기능 때문에 바꾸지 않는다.
- 비밀값·개인정보·AI 대화 전문을 커밋하지 않는다.
